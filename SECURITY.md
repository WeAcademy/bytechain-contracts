# Security Policy

## Supported versions

The contracts are pre-release and not deployed to mainnet. Only the `main`
branch is supported.

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through
GitHub's [private vulnerability reporting](https://github.com/WeAcademy/bytechain-contracts/security/advisories/new)
for this repository. Include the affected contract or package, steps to
reproduce, and the impact you expect.

The maintainer, [@TomikeDS](https://github.com/TomikeDS), will acknowledge the
report and keep you updated while it is investigated and fixed.
