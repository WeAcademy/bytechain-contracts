# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive
feedback, and do not harass anyone. Harassment, discriminatory language,
personal attacks and publishing other people's private information are not
acceptable in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour to the maintainer,
[@TomikeDS](https://github.com/TomikeDS). Reports are handled in confidence.
The maintainer may remove comments, close issues or pull requests, or block
contributors who break this code.
